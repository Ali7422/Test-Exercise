
# Selenium Automation Testing Framework

## About the Project
A web automation testing project built using
Java, Selenium WebDriver, TestNG, and Maven.

## Technologies
- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA

## Project Features
- Automated UI Testing
- Web Element Interactions
- Browser Navigation
- Test Assertions
- Test Execution and Reporting

## Project Structure
src/
pom.xml
.gitignore

## How to Run
1. Clone the repository.
2. Open the project using IntelliJ IDEA.
3. Install Maven dependencies.
4. Run the TestNG test classes.
